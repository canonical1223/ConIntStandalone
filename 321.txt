Подготовил обновлённую версию GeoSchemeDocs.cmake. В ней исправлена логика регистрации целей документации и учтены пути AUTOGEN, которые раньше задавались вручную.
Основные изменения:
	•	Документация отдельного модуля. docs_<Module> собирает документацию только выбранного модуля.
	•	Принудительная пересборка модуля. docs_<Module>_rebuild удаляет его HTML и запускает генерацию заново.
	•	Общая генерация. docs_GeoScheme_index сначала собирает все зарегистрированные модули, затем формирует общий индекс.
	•	Полная пересборка. docs_rebuild_all удаляет каталог документации и последовательно запускает генерацию всех модулей и индекса.
	•	Проверка отсутствующей документации. При конфигурации проверяется наличие HTML-файлов и stamp-файла. Если HTML отсутствует, модуль регистрируется на генерацию.
	•	Порядок сборки. QDoc запускается после сборки основного target и обнаруженных AUTOGEN-target, от которых зависят заголовки.
	•		•	Пути AUTOGEN. Они определяются по свойствам CMake-целей и структуре каталогов. Пути GeoProImportDao_autogen/include и GeoSchemeImpExp_autogen/include не зашиты в код.
	•	Документация выключена. При GEOSCHEME_BUILD_DOCS=OFF функции завершаются без поиска Qt и QDoc и без создания целей документации.
	•	Кроссплатформенность. Пути компилятора и системных include-каталогов берутся из настроек CMake, а не из фиксированной версии MinGW.
	•	Установка документации. Добавлена отдельная опция установки HTML-документации. Она выключена по умолчанию.
Важный момент: проверка отсутствия HTML выполняется на этапе конфигурации CMake. Если HTML-файлы удалить уже после конфигурации, нужно повторно запустить CMake или использовать принудительную цель docs_<Module>_rebuild / docs_rebuild_all.

GeoSchemeDocs.cmake
# =============================================================================
# GeoSchemeDocs.cmake
#
# Централизованный модуль сборки QDoc-документации проекта GeoScheme.
#
# Возможности:
#   docs_<Module>          - генерация документации отдельного модуля;
#   docs_<Module>_rebuild  - принудительная пересборка документации модуля;
#   docs_GeoScheme_index   - генерация документации всех модулей и индекса;
#   docs_rebuild_all       - полная пересборка документации.
#
# Совместимость: CMake 3.14+
# Qt: Qt 5
#
# ВАЖНО:
#   QDoc не запускается при обычной сборке приложения.
#   QDoc запускается только при вызове документационных целей.
#   Перед QDoc собираются target модуля и AUTOGEN-зависимости.
# =============================================================================

macro(_gs_compute_qt_env)

    find_package(Qt5 REQUIRED COMPONENTS Core)

    if(NOT Qt5Core_DIR)
        message(FATAL_ERROR
            "[Docs] Qt5Core_DIR is not defined."
        )
    endif()

    # -------------------------------------------------------------------------
    # Qt root
    # -------------------------------------------------------------------------

    if(GEOSCHEME_QDOC_QT_ROOT)
        get_filename_component(
            _gs_qt_root
            "${GEOSCHEME_QDOC_QT_ROOT}"
            ABSOLUTE
        )
    else()

        set(_gs_qt_root "")

        set(_gs_qt_root_candidates
            "${Qt5Core_DIR}/../../.."
            "${Qt5Core_DIR}/../../../.."
            "${Qt5Core_DIR}/../.."
        )

        foreach(_candidate IN LISTS _gs_qt_root_candidates)

            get_filename_component(
                _candidate
                "${_candidate}"
                ABSOLUTE
            )

            if(IS_DIRECTORY "${_candidate}/include")
                set(_gs_qt_root "${_candidate}")
                break()
            endif()

        endforeach()

    endif()

    if(NOT _gs_qt_root)
        message(FATAL_ERROR
            "[Docs] Cannot determine Qt installation root. "
            "Set GEOSCHEME_QDOC_QT_ROOT."
        )
    endif()

    set(_gs_qt_bin
        "${_gs_qt_root}/bin"
    )

    set(_gs_qt_headers
        "${_gs_qt_root}/include"
    )

    if(DEFINED Qt5Core_VERSION)
        set(_gs_qt_version "${Qt5Core_VERSION}")
    else()
        set(_gs_qt_version "${Qt5_VERSION}")
    endif()

    # -------------------------------------------------------------------------
    # Qt documentation
    # -------------------------------------------------------------------------

    if(NOT GEOSCHEME_QDOC_QT_DOCS)

        get_filename_component(
            _gs_qt_version_root
            "${_gs_qt_root}"
            DIRECTORY
        )

        get_filename_component(
            _gs_qt_sdk_root
            "${_gs_qt_version_root}"
            DIRECTORY
        )

        set(_gs_qt_docs_candidates
            "${_gs_qt_sdk_root}/Docs/Qt-${_gs_qt_version}"
            "${_gs_qt_root}/Docs/Qt-${_gs_qt_version}"
            "${_gs_qt_root}/share/qt5/doc"
            "${_gs_qt_root}/share/doc/qt${_gs_qt_version}"
            "${_gs_qt_root}/share/doc/qt5"
        )

        foreach(_candidate IN LISTS _gs_qt_docs_candidates)

            if(IS_DIRECTORY "${_candidate}")
                set(GEOSCHEME_QDOC_QT_DOCS
                    "${_candidate}"
                    CACHE PATH
                    "Qt documentation directory used by QDoc"
                    FORCE
                )
                break()
            endif()

        endforeach()

    endif()

    set(_gs_qt_docs "${GEOSCHEME_QDOC_QT_DOCS}")

    if(NOT IS_DIRECTORY "${_gs_qt_docs}")
        message(WARNING
            "[Docs] Qt documentation directory was not found: "
            "${_gs_qt_docs}"
        )
    endif()

    # -------------------------------------------------------------------------
    # Qt include directories
    # -------------------------------------------------------------------------

    if(NOT IS_DIRECTORY "${_gs_qt_headers}")

        if(Qt5Core_INCLUDE_DIRS)
            list(GET Qt5Core_INCLUDE_DIRS 0 _gs_qt_include_candidate)

            if(_gs_qt_include_candidate MATCHES "[/\\\\]QtCore$")
                get_filename_component(
                    _gs_qt_headers
                    "${_gs_qt_include_candidate}/.."
                    ABSOLUTE
                )
            else()
                set(_gs_qt_headers "${_gs_qt_include_candidate}")
            endif()
        endif()

    endif()

    # -------------------------------------------------------------------------
    # Системные include-пути компилятора.
    #
    # Используются значения CMake, а не фиксированные пути MinGW.
    # Это позволяет работать с разными компиляторами и платформами.
    # -------------------------------------------------------------------------

    set(_gs_compiler_includes
        "${CMAKE_CXX_IMPLICIT_INCLUDE_DIRECTORIES}"
    )

    if(CMAKE_CXX_COMPILER)
        get_filename_component(
            _gs_compiler_bin
            "${CMAKE_CXX_COMPILER}"
            DIRECTORY
        )
    else()
        set(_gs_compiler_bin "")
    endif()

    message(STATUS "[Docs] Qt root       = ${_gs_qt_root}")
    message(STATUS "[Docs] Qt version    = ${_gs_qt_version}")
    message(STATUS "[Docs] Qt headers    = ${_gs_qt_headers}")
    message(STATUS "[Docs] Qt docs       = ${_gs_qt_docs}")
    message(STATUS "[Docs] C++ compiler  = ${CMAKE_CXX_COMPILER}")

endmacro()

macro(_gs_find_qdoc)

    if(QDOC_EXECUTABLE)

        if(NOT EXISTS "${QDOC_EXECUTABLE}")
            message(FATAL_ERROR
                "[Docs] QDOC_EXECUTABLE does not exist: "
                "${QDOC_EXECUTABLE}"
            )
        endif()

    else()

        find_program(
            _gs_qdoc_candidate
            NAMES qdoc qdoc.exe
            PATHS "${_gs_qt_bin}"
            NO_DEFAULT_PATH
        )

        if(NOT _gs_qdoc_candidate)

            find_program(
                _gs_qdoc_candidate_fallback
                NAMES qdoc qdoc.exe
            )

            if(_gs_qdoc_candidate_fallback)
                set(
                    _gs_qdoc_candidate
                    "${_gs_qdoc_candidate_fallback}"
                )
            endif()

        endif()

        if(NOT _gs_qdoc_candidate)
            message(FATAL_ERROR
                "[Docs] QDoc was not found. "
                "Set QDOC_EXECUTABLE to the full path."
            )
        endif()

        set(
            QDOC_EXECUTABLE
            "${_gs_qdoc_candidate}"
            CACHE FILEPATH
            "Path to QDoc executable"
        )

    endif()

    message(STATUS "[Docs] QDoc executable = ${QDOC_EXECUTABLE}")

endmacro()

macro(_gs_compute_safe_path)

    file(
        TO_CMAKE_PATH
        "$ENV{PATH}"
        _gs_path_entries
    )

    set(_gs_safe_path_entries "")

    if(IS_DIRECTORY "${_gs_qt_bin}")
        list(APPEND
            _gs_safe_path_entries
            "${_gs_qt_bin}"
        )
    endif()

    if(_gs_compiler_bin AND IS_DIRECTORY "${_gs_compiler_bin}")
        list(APPEND
            _gs_safe_path_entries
            "${_gs_compiler_bin}"
        )
    endif()

    list(APPEND
        _gs_safe_path_entries
        ${_gs_path_entries}
    )

    list(REMOVE_DUPLICATES _gs_safe_path_entries)

    file(
        TO_NATIVE_PATH
        "${_gs_safe_path_entries}"
        _gs_safe_path
    )

    message(STATUS "[Docs] QDoc PATH = ${_gs_safe_path}")

endmacro()

# 5. ПОЛУЧЕНИЕ AUTOGEN INCLUDE-КАТАЛОГА
# =============================================================================

function(_gs_get_target_autogen_include _target _out_var)

    set(_result "")

    if(NOT TARGET "${_target}")
        set(${_out_var} "" PARENT_SCOPE)
        return()
    endif()

    get_target_property(
        _autogen_dir
        "${_target}"
        AUTOGEN_BUILD_DIR
    )

    if(NOT _autogen_dir OR _autogen_dir MATCHES "-NOTFOUND$")

        get_target_property(
            _automoc
            "${_target}"
            AUTOMOC
        )

        get_target_property(
            _autouic
            "${_target}"
            AUTOUIC
        )

        get_target_property(
            _autorcc
            "${_target}"
            AUTORCC
        )

        if(
            _automoc OR
            _autouic OR
            _autorcc OR
            CMAKE_AUTOMOC OR
            CMAKE_AUTOUIC OR
            CMAKE_AUTORCC
        )

            get_target_property(
                _binary_dir
                "${_target}"
                BINARY_DIR
            )

            if(_binary_dir)
                set(
                    _autogen_dir
                    "${_binary_dir}/${_target}_autogen"
                )
            endif()

        endif()

    endif()

    if(_autogen_dir AND NOT _autogen_dir MATCHES "\\$<")

        set(
            _result
            "${_autogen_dir}/include"
        )

    endif()

    set(${_out_var} "${_result}" PARENT_SCOPE)

endfunction()

# 6. РЕКУРСИВНЫЙ СБОР INCLUDE-ПУТЕЙ TARGET
# =============================================================================

function(
    _gs_collect_target_includes
    _target
    _out_includes
    _out_targets
    _visited
)

    if(NOT TARGET "${_target}")
        set(${_out_includes} "" PARENT_SCOPE)
        set(${_out_targets} "${_visited}" PARENT_SCOPE)
        return()
    endif()

    if("${_target}" IN_LIST _visited)
        set(${_out_includes} "" PARENT_SCOPE)
        set(${_out_targets} "${_visited}" PARENT_SCOPE)
        return()
    endif()

    list(APPEND _visited "${_target}")

    set(_includes "")
    set(_targets "${_target}")

    get_target_property(
        _source_dir
        "${_target}"
        SOURCE_DIR
    )

    foreach(_property
        INCLUDE_DIRECTORIES
        INTERFACE_INCLUDE_DIRECTORIES
    )

        get_target_property(
            _dirs
            "${_target}"
            "${_property}"
        )

        if(_dirs)

            foreach(_dir IN LISTS _dirs)

                set(_resolved_dir "")

                if(_dir MATCHES "^\\$<BUILD_INTERFACE:([^>]*)>$")
                    set(_resolved_dir "${CMAKE_MATCH_1}")
                elseif(NOT _dir MATCHES "\\$<")
                    set(_resolved_dir "${_dir}")
                endif()

                if(_resolved_dir)

                    if(NOT IS_ABSOLUTE "${_resolved_dir}")
                        get_filename_component(
                            _resolved_dir
                            "${_resolved_dir}"
                            ABSOLUTE
                            BASE_DIR "${_source_dir}"
                        )
                    endif()

                    list(APPEND _includes "${_resolved_dir}")

                endif()

            endforeach()

        endif()

    endforeach()

    _gs_get_target_autogen_include(
        "${_target}"
        _autogen_include
    )

    if(_autogen_include)
        list(APPEND _includes "${_autogen_include}")
    endif()

    foreach(_property
        LINK_LIBRARIES
        INTERFACE_LINK_LIBRARIES
    )

        get_target_property(
            _libraries
            "${_target}"
            "${_property}"
        )

        if(_libraries)

            foreach(_library IN LISTS _libraries)

                if(
                    _library MATCHES "\\$<" OR
                    _library STREQUAL "debug" OR
                    _library STREQUAL "optimized" OR
                    _library STREQUAL "general" OR
                    NOT TARGET "${_library}"
                )
                    continue()
                endif()

                _gs_collect_target_includes(
                    "${_library}"
                    _dependency_includes
                    _dependency_targets
                    "${_visited}"
                )

                list(APPEND _includes ${_dependency_includes})
                list(APPEND _targets ${_dependency_targets})

                set(_visited ${_dependency_targets})

            endforeach()

        endif()

    endforeach()

    list(REMOVE_DUPLICATES _includes)
    list(REMOVE_DUPLICATES _targets)

    set(${_out_includes} "${_includes}" PARENT_SCOPE)
    set(${_out_targets} "${_targets}" PARENT_SCOPE)

endfunction()

# =============================================================================
# 7. СБОР AUTOGEN ИЗ ТЕКУЩЕГО КАТАЛОГА И ПОДКАТАЛОГОВ
#
# Это нужно для случаев, когда AUTOGEN-target находится во вложенном
# подкаталоге и не является прямой зависимостью основного target.
#
# Пути вычисляются по реальным свойствам CMake-целей.
# Названия конкретных модулей и пути к ним не зашиваются.
# =============================================================================

function(_gs_collect_directory_autogen _directory _out_includes _out_targets)

    set(_includes "")
    set(_targets "")

    get_property(
        _directory_targets
        DIRECTORY "${_directory}"
        PROPERTY BUILDSYSTEM_TARGETS
    )

    foreach(_target IN LISTS _directory_targets)

        _gs_get_target_autogen_include(
            "${_target}"
            _autogen_include
        )

        if(_autogen_include)

            list(APPEND _includes "${_autogen_include}")
            list(APPEND _targets "${_target}")

        endif()

    endforeach()

    get_property(
        _subdirectories
        DIRECTORY "${_directory}"
        PROPERTY SUBDIRECTORIES
    )

    foreach(_subdirectory IN LISTS _subdirectories)

        _gs_collect_directory_autogen(
            "${_subdirectory}"
            _sub_includes
            _sub_targets
        )

        list(APPEND _includes ${_sub_includes})
        list(APPEND _targets ${_sub_targets})

    endforeach()

    list(REMOVE_DUPLICATES _includes)
    list(REMOVE_DUPLICATES _targets)

    set(${_out_includes} "${_includes}" PARENT_SCOPE)
    set(${_out_targets} "${_targets}" PARENT_SCOPE)

endfunction()

# 8. ФОРМИРОВАНИЕ СПИСКА -I ДЛЯ QDOC
# =============================================================================

function(
    _gs_build_include_path_args
    _module_name
    _qt_headers
    _out_args
    _out_build_targets
)

    set(_args "")
    set(_regular_includes "")
    set(_autogen_includes "")
    set(_build_targets "")

    # -------------------------------------------------------------------------
    # Системные заголовки компилятора
    # -------------------------------------------------------------------------

    foreach(_path IN LISTS _gs_compiler_includes)

        if(IS_DIRECTORY "${_path}")
            list(APPEND _regular_includes "${_path}")
        endif()

    endforeach()

    # -------------------------------------------------------------------------
    # Qt headers
    # -------------------------------------------------------------------------

    if(IS_DIRECTORY "${_qt_headers}")
        list(APPEND _regular_includes "${_qt_headers}")
    endif()

    foreach(_qt_module IN LISTS GEOSCHEME_QDOC_QT_MODULES)

        if(IS_DIRECTORY "${_qt_headers}/${_qt_module}")

            list(APPEND
                _regular_includes
                "${_qt_headers}/${_qt_module}"
            )

        endif()

    endforeach()

    # -------------------------------------------------------------------------
    # Include-пути основного target и его зависимостей
    # -------------------------------------------------------------------------

    if(TARGET "${_module_name}")

        _gs_collect_target_includes(
            "${_module_name}"
            _target_includes
            _target_dependencies
            ""
        )

        list(APPEND _regular_includes ${_target_includes})
        list(APPEND _build_targets ${_target_dependencies})

    else()

        message(WARNING
            "[Docs] ${_module_name}: CMake target not found."
        )

    endif()

    # -------------------------------------------------------------------------
    # AUTOGEN из всех целей внутри каталога модуля и подкаталогов
    # -------------------------------------------------------------------------

    _gs_collect_directory_autogen(
        "${CMAKE_CURRENT_SOURCE_DIR}"
        _directory_autogen_includes
        _directory_autogen_targets
    )

    list(APPEND _autogen_includes ${_directory_autogen_includes})
    list(APPEND _build_targets ${_directory_autogen_targets})

    list(REMOVE_DUPLICATES _regular_includes)
    list(REMOVE_DUPLICATES _autogen_includes)
    list(REMOVE_DUPLICATES _build_targets)

    # -------------------------------------------------------------------------
    # Формирование -I
    # -------------------------------------------------------------------------

    foreach(_path IN LISTS _regular_includes)

        if(IS_DIRECTORY "${_path}")
            list(APPEND _args "-I${_path}")
        endif()

    endforeach()

    # AUTOGEN-каталоги могут ещё не существовать на этапе конфигурации.
    # Поэтому добавляем рассчитанные пути независимо от их наличия.
    # До запуска QDoc соответствующие targets будут собраны.
    foreach(_path IN LISTS _autogen_includes)

        if(_path)
            list(APPEND _args "-I${_path}")
        endif()

    endforeach()

    list(REMOVE_DUPLICATES _args)

    message(STATUS
        "[Docs] ${_module_name}: regular include paths = "
        "${_regular_includes}"
    )

    message(STATUS
        "[Docs] ${_module_name}: AUTOGEN include paths = "
        "${_autogen_includes}"
    )

    message(STATUS
        "[Docs] ${_module_name}: AUTOGEN build targets = "
        "${_directory_autogen_targets}"
    )

    set(${_out_args} "${_args}" PARENT_SCOPE)
    set(${_out_build_targets} "${_build_targets}" PARENT_SCOPE)

endfunction()

# =============================================================================
# 9. ДОПОЛНИТЕЛЬНЫЕ ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ AUTOGEN
# =============================================================================

function(
    _gs_get_autogen_environment
    _out_environment
    _out_includes
)

    set(_environment "")
    set(_includes "")

    foreach(_mapping IN LISTS GEOSCHEME_QDOC_AUTOGEN_ENV)

        string(REPLACE "=" ";" _mapping_parts "${_mapping}")

        list(LENGTH _mapping_parts _mapping_length)

        if(NOT _mapping_length EQUAL 2)
            message(FATAL_ERROR
                "[Docs] Invalid GEOSCHEME_QDOC_AUTOGEN_ENV entry: "
                "${_mapping}"
            )
        endif()

        list(GET _mapping_parts 0 _env_name)
        list(GET _mapping_parts 1 _target_name)

        if(NOT TARGET "${_target_name}")
            message(FATAL_ERROR
                "[Docs] AUTOGEN environment target does not exist: "
                "${_target_name}"
            )
        endif()

        _gs_get_target_autogen_include(
            "${_target_name}"
            _autogen_include
        )

        if(NOT _autogen_include)
            message(FATAL_ERROR
                "[Docs] Cannot determine AUTOGEN include directory "
                "for target ${_target_name}"
            )
        endif()

        list(APPEND
            _environment
            "${_env_name}=${_autogen_include}"
        )

        list(APPEND _includes "${_autogen_include}")

    endforeach()

    set(${_out_environment} "${_environment}" PARENT_SCOPE)
    set(${_out_includes} "${_includes}" PARENT_SCOPE)

endfunction()

function(_gs_write_qdoc_args_log _log_name _description _args)

    get_filename_component(
        _log_dir
        "${GEOSCHEME_QDOC_HTML_DIR}/../logs"
        ABSOLUTE
    )

    file(MAKE_DIRECTORY "${_log_dir}")

    string(
        REPLACE
        ";"
        "\n"
        _pretty_args
        "${_args}"
    )

    file(WRITE
        "${_log_dir}/${_log_name}"
        "# ${_description}\n"
        "# Generated by GeoSchemeDocs.cmake\n\n"
        "${_pretty_args}\n"
    )

    message(STATUS
        "[Docs] QDoc arguments log = ${_log_dir}/${_log_name}"
    )

endfunction()

# 11. ИНИЦИАЛИЗАЦИЯ QDOC

macro(_gs_initialize_qdoc)

# =============================================================================
# 12. ЗАВИСИМОСТИ ИСХОДНЫХ ФАЙЛОВ QDOC
# =============================================================================

function(_gs_collect_qdoc_dependencies _target _qdocconf _out_var)

    set(_dependencies "${_qdocconf}")

    if(TARGET "${_target}")

        get_target_property(
            _sources
            "${_target}"
            SOURCES
        )

        foreach(_source IN LISTS _sources)

            if(_source MATCHES "\\$<")
                continue()
            endif()

            if(NOT IS_ABSOLUTE "${_source}")

                get_target_property(
                    _source_dir
                    "${_target}"
                    SOURCE_DIR
                )

                get_filename_component(
                    _source
                    "${_source}"
                    ABSOLUTE
                    BASE_DIR "${_source_dir}"
                )

            endif()

            if(EXISTS "${_source}")
                list(APPEND _dependencies "${_source}")
            endif()

        endforeach()

    endif()

    list(REMOVE_DUPLICATES _dependencies)

    set(${_out_var} "${_dependencies}" PARENT_SCOPE)

endfunction()

# =============================================================================
# 13. РЕГИСТРАЦИЯ ДОКУМЕНТАЦИИ МОДУЛЯ
#
# Использование:
#
# gs_add_doc_target(GeoProjectData GeoProjectData.qdocconf)
#
# При необходимости дополнительные AUTOGEN-переменные можно задать
# через GEOSCHEME_QDOC_AUTOGEN_ENV.
# =============================================================================

function(gs_add_doc_target MODULE_NAME QDOCCONF_FILENAME)

    # -------------------------------------------------------------------------
    # Документация выключена
    # -------------------------------------------------------------------------

    if(NOT GEOSCHEME_BUILD_DOCS)
        return()
    endif()

    if("${MODULE_NAME}" STREQUAL "" OR
       "${QDOCCONF_FILENAME}" STREQUAL "")

        message(FATAL_ERROR
            "[Docs] gs_add_doc_target requires MODULE_NAME "
            "and QDOCCONF_FILENAME."
        )

    endif()

    if(TARGET "docs_${MODULE_NAME}")

        message(FATAL_ERROR
            "[Docs] Documentation target already exists: "
            "docs_${MODULE_NAME}"
        )

    endif()

    # -------------------------------------------------------------------------
    # Qt / QDoc
    # -------------------------------------------------------------------------

    _gs_initialize_qdoc()

    # -------------------------------------------------------------------------
    # Пути
    # -------------------------------------------------------------------------

    get_filename_component(
        _gs_html_root
        "${GEOSCHEME_QDOC_HTML_DIR}"
        ABSOLUTE
        BASE_DIR "${CMAKE_SOURCE_DIR}"
    )

    if(IS_ABSOLUTE "${QDOCCONF_FILENAME}")

        set(_gs_mod_conf "${QDOCCONF_FILENAME}")

    else()

        get_filename_component(
            _gs_mod_conf
            "${QDOCCONF_FILENAME}"
            ABSOLUTE
            BASE_DIR "${CMAKE_CURRENT_SOURCE_DIR}"
        )

    endif()

    if(NOT EXISTS "${_gs_mod_conf}")

        message(FATAL_ERROR
            "[Docs] ${MODULE_NAME}: QDoc configuration not found: "
            "${_gs_mod_conf}"
        )

    endif()

    set(_gs_out_dir
        "${_gs_html_root}/${MODULE_NAME}"
    )

    set(_gs_stamp
        "${_gs_out_dir}/.cmake_docs_stamp"
    )

    # -------------------------------------------------------------------------
    # Include-пути
    # -------------------------------------------------------------------------

    _gs_build_include_path_args(
        "${MODULE_NAME}"
        "${_gs_qt_headers}"
        _gs_include_path_args
        _gs_build_targets
    )

    # -------------------------------------------------------------------------
    # Дополнительные переменные AUTOGEN
    # -------------------------------------------------------------------------

    _gs_get_autogen_environment(
        _gs_autogen_environment
        _gs_autogen_environment_includes
    )

    list(APPEND
        _gs_include_path_args
        ${_gs_autogen_environment_includes}
    )

    foreach(_path IN LISTS _gs_autogen_environment_includes)

        if(_path)
            list(APPEND _gs_include_path_args "-I${_path}")
        endif()

    endforeach()

    list(REMOVE_DUPLICATES _gs_include_path_args)

    # -------------------------------------------------------------------------
    # Лог аргументов
    # -------------------------------------------------------------------------

    _gs_write_qdoc_args_log(
        "${MODULE_NAME}_qdoc_args.txt"
        "QDoc include arguments for ${MODULE_NAME}"
        "${_gs_include_path_args}"
    )

    message(STATUS "[Docs] ${MODULE_NAME}: output = ${_gs_out_dir}")
    message(STATUS "[Docs] ${MODULE_NAME}: config = ${_gs_mod_conf}")

    # -------------------------------------------------------------------------
    # Проверка существующей документации.
    #
    # Если каталог существует, но HTML отсутствует, stamp удаляется.
    # Это заставляет CMake выполнить QDoc при следующем вызове цели.
    # -------------------------------------------------------------------------

    file(GLOB_RECURSE
        _gs_existing_html
        LIST_DIRECTORIES FALSE
        "${_gs_out_dir}/*.html"
    )

    if(NOT _gs_existing_html OR NOT EXISTS "${_gs_stamp}")

        file(REMOVE "${_gs_stamp}")

        message(STATUS
            "[Docs] ${MODULE_NAME}: documentation is missing or incomplete; "
            "QDoc generation registered."
        )

    else()

        message(STATUS
            "[Docs] ${MODULE_NAME}: existing HTML documentation found."
        )

    endif()

    # -------------------------------------------------------------------------
    # Зависимости исходных файлов
    # -------------------------------------------------------------------------

    _gs_collect_qdoc_dependencies(
        "${MODULE_NAME}"
        "${_gs_mod_conf}"
        _gs_qdoc_dependencies
    )

    # -------------------------------------------------------------------------
    # QDoc custom command
    #
    # QDoc выполняется только после завершения:
    #   1. основного target модуля;
    #   2. AUTOGEN-target, найденных в каталоге модуля;
    #   3. дополнительных target из графа зависимостей.
    # -------------------------------------------------------------------------

    add_custom_command(
        OUTPUT "${_gs_stamp}"

        COMMAND
            "${CMAKE_COMMAND}" -E make_directory
            "${_gs_out_dir}"

        COMMAND
            "${CMAKE_COMMAND}" -E env

            "QT_INSTALL_DOCS=${_gs_qt_docs}"
            "QT_INSTALL_HEADERS=${_gs_qt_headers}"
            "QT_INSTALL_PREFIX=${_gs_qt_root}"
            "QT_VERSION=${_gs_qt_version}"
            "QT_VER=${_gs_qt_version}"

            "PATH=${_gs_safe_path}"

            "QDOC_DISABLE_CLANG=1"

            ${_gs_autogen_environment}

            "${QDOC_EXECUTABLE}"
            --no-link-errors
            ${_gs_include_path_args}
            "${_gs_mod_conf}"

        COMMAND
            "${CMAKE_COMMAND}" -E touch
            "${_gs_stamp}"

        DEPENDS
            ${_gs_qdoc_dependencies}
            "${QDOC_EXECUTABLE}"

        WORKING_DIRECTORY
            "${CMAKE_CURRENT_SOURCE_DIR}"

        COMMENT
            "[Docs] QDoc: ${MODULE_NAME}"

        VERBATIM
    )

    # -------------------------------------------------------------------------
    # Цель документации
    # -------------------------------------------------------------------------

    add_custom_target(
        "docs_${MODULE_NAME}"
        DEPENDS "${_gs_stamp}"
    )

    # Основной target должен быть собран до запуска QDoc.
    if(TARGET "${MODULE_NAME}")

        add_dependencies(
            "docs_${MODULE_NAME}"
            "${MODULE_NAME}"
        )

    endif()

    # AUTOGEN и связанные target.
    foreach(_dependency IN LISTS _gs_build_targets)

        if(TARGET "${_dependency}" AND
           NOT "${_dependency}" STREQUAL "${MODULE_NAME}")

            add_dependencies(
                "docs_${MODULE_NAME}"
                "${_dependency}"
            )

        endif()

    endforeach()

    # Дополнительные target, заданные через AUTOGEN_ENV.
    foreach(_mapping IN LISTS GEOSCHEME_QDOC_AUTOGEN_ENV)

        string(REPLACE "=" ";" _mapping_parts "${_mapping}")

        list(GET _mapping_parts 1 _target_name)

        if(TARGET "${_target_name}")

            add_dependencies(
                "docs_${MODULE_NAME}"
                "${_target_name}"
            )

        endif()

    endforeach()

    # -------------------------------------------------------------------------
    # Принудительная пересборка документации отдельного модуля
    # -------------------------------------------------------------------------

    add_custom_target(
        "docs_${MODULE_NAME}_rebuild"

        COMMAND
            "${CMAKE_COMMAND}" -E remove_directory
            "${_gs_out_dir}"

        COMMAND
            "${CMAKE_COMMAND}" --build
            "${CMAKE_BINARY_DIR}"
            --config "$<CONFIG>"
            --target "docs_${MODULE_NAME}"

        COMMENT
            "[Docs] Force rebuild documentation: ${MODULE_NAME}"

        VERBATIM
    )

    # -------------------------------------------------------------------------
    # Регистрация модуля
    # -------------------------------------------------------------------------

    set_property(
        GLOBAL APPEND PROPERTY
        GS_DOC_MODULE_TARGETS
        "docs_${MODULE_NAME}"
    )

    set_property(
        GLOBAL APPEND PROPERTY
        GS_DOC_MODULE_STAMPS
        "${_gs_stamp}"
    )

    set_property(
        GLOBAL APPEND PROPERTY
        GS_DOC_MODULE_NAMES
        "${MODULE_NAME}"
    )

    message(STATUS
        "[Docs] Registered documentation target: docs_${MODULE_NAME}"
    )

endfunction()

# =============================================================================
# 14. ФИНАЛИЗАЦИЯ ОБЩЕГО ИНДЕКСА
#
# Вызывается один раз из корневого CMakeLists.txt после всех add_subdirectory.
# =============================================================================

function(gs_finalize_doc_index)

    if(NOT GEOSCHEME_BUILD_DOCS)
        return()
    endif()

    if(TARGET docs_GeoScheme_index)

        message(FATAL_ERROR
            "[Docs] gs_finalize_doc_index() has already been called."
        )

    endif()

    _gs_initialize_qdoc()

    get_filename_component(
        _gs_html_root
        "${GEOSCHEME_QDOC_HTML_DIR}"
        ABSOLUTE
        BASE_DIR "${CMAKE_SOURCE_DIR}"
    )

    get_filename_component(
        _gs_main_conf
        "${GEOSCHEME_QDOC_INDEX_CONFIG}"
        ABSOLUTE
        BASE_DIR "${CMAKE_SOURCE_DIR}"
    )

    if(NOT EXISTS "${_gs_main_conf}")

        message(FATAL_ERROR
            "[Docs] Main QDoc configuration not found: "
            "${_gs_main_conf}"
        )

    endif()

    get_filename_component(
        _gs_main_conf_dir
        "${_gs_main_conf}"
        DIRECTORY
    )

    set(_gs_out_dir
        "${_gs_html_root}/GeoScheme"
    )

    set(_gs_stamp
        "${_gs_out_dir}/.cmake_docs_stamp"
    )

    get_property(
        _gs_module_targets
        GLOBAL PROPERTY GS_DOC_MODULE_TARGETS
    )

    get_property(
        _gs_module_stamps
        GLOBAL PROPERTY GS_DOC_MODULE_STAMPS
    )

    message(STATUS
        "[Docs] Registered modules = ${_gs_module_targets}"
    )

    # -------------------------------------------------------------------------
    # Include-пути Qt и компилятора
    # -------------------------------------------------------------------------

    set(_gs_index_include_args "")

    foreach(_path IN LISTS _gs_compiler_includes)

        if(IS_DIRECTORY "${_path}")
            list(APPEND _gs_index_include_args "-I${_path}")
        endif()

    endforeach()

    if(IS_DIRECTORY "${_gs_qt_headers}")
        list(APPEND
            _gs_index_include_args
            "-I${_gs_qt_headers}"
        )
    endif()

    foreach(_qt_module IN LISTS GEOSCHEME_QDOC_QT_MODULES)

        if(IS_DIRECTORY "${_gs_qt_headers}/${_qt_module}")

            list(APPEND
                _gs_index_include_args
                "-I${_gs_qt_headers}/${_qt_module}"
            )

        endif()

    endforeach()

    list(REMOVE_DUPLICATES _gs_index_include_args)

    _gs_write_qdoc_args_log(
        "GeoScheme_index_qdoc_args.txt"
        "QDoc include arguments for GeoScheme index"
        "${_gs_index_include_args}"
    )

    # -------------------------------------------------------------------------
    # Проверка существующего индекса
    # -------------------------------------------------------------------------

    file(GLOB_RECURSE
        _gs_existing_index_html
        LIST_DIRECTORIES FALSE
        "${_gs_out_dir}/*.html"
    )

    if(NOT _gs_existing_index_html OR NOT EXISTS "${_gs_stamp}")

        file(REMOVE "${_gs_stamp}")

        message(STATUS
            "[Docs] GeoScheme index: generation required."
        )

    else()

        message(STATUS
            "[Docs] GeoScheme index: existing HTML found."
        )

    endif()

    # -------------------------------------------------------------------------
    # Генерация общего индекса
    #
    # Зависимости модулей гарантируют, что сначала завершится QDoc каждого
    # модуля, а уже после этого будет запущен QDoc общего индекса.
    # -------------------------------------------------------------------------

    add_custom_command(
        OUTPUT "${_gs_stamp}"

        COMMAND
            "${CMAKE_COMMAND}" -E make_directory
            "${_gs_out_dir}"

        COMMAND
            "${CMAKE_COMMAND}" -E env

            "QT_INSTALL_DOCS=${_gs_qt_docs}"
            "QT_INSTALL_HEADERS=${_gs_qt_headers}"
            "QT_INSTALL_PREFIX=${_gs_qt_root}"
            "QT_VERSION=${_gs_qt_version}"
            "QT_VER=${_gs_qt_version}"

            "PATH=${_gs_safe_path}"

            "QDOC_DISABLE_CLANG=1"

            "${QDOC_EXECUTABLE}"
            --no-link-errors
            ${_gs_index_include_args}
            "${_gs_main_conf}"

        COMMAND
            "${CMAKE_COMMAND}" -E touch
            "${_gs_stamp}"

        DEPENDS
            "${_gs_main_conf}"
            "${QDOC_EXECUTABLE}"
            ${_gs_module_stamps}

        WORKING_DIRECTORY
            "${_gs_main_conf_dir}"

        COMMENT
            "[Docs] QDoc: GeoScheme index"

        VERBATIM
    )

    # -------------------------------------------------------------------------
    # Общая цель документации
    # -------------------------------------------------------------------------

    add_custom_target(
        docs_GeoScheme_index
        DEPENDS "${_gs_stamp}"
    )

    if(_gs_module_targets)

        add_dependencies(
            docs_GeoScheme_index
            ${_gs_module_targets}
        )

    endif()

    # -------------------------------------------------------------------------
    # Полная принудительная пересборка документации
    # -------------------------------------------------------------------------

    add_custom_target(
        docs_rebuild_all

        COMMAND
            "${CMAKE_COMMAND}" -E remove_directory
            "${_gs_html_root}"

        COMMAND
            "${CMAKE_COMMAND}" --build
            "${CMAKE_BINARY_DIR}"
            --config "$<CONFIG>"
            --target docs_GeoScheme_index

        COMMENT
            "[Docs] Full documentation rebuild from scratch"

        VERBATIM
    )

    message(STATUS
        "[Docs] Registered target: docs_GeoScheme_index"
    )

    message(STATUS
        "[Docs] Registered target: docs_rebuild_all"
    )

endfunction()

Как подключить модуль
В корневом CMakeLists.txt:
include("${CMAKE_SOURCE_DIR}/cmake/GeoSchemeDocs.cmake")
Вызов gs_finalize_doc_index() должен находиться после всех add_subdirectory():
if(GEOSCHEME_BUILD_DOCS)
    gs_finalize_doc_index()
endif()
В CMakeLists.txt каждого документируемого модуля:
if(GEOSCHEME_BUILD_DOCS)
    gs_add_doc_target(GeoProjectData GeoProjectData.qdocconf)
endif()
Настройка AUTOGEN-путей
Для сохранения прежнего механизма передачи переменных в QDoc можно использовать настройку без прописывания абсолютных путей:
set(GEOSCHEME_QDOC_AUTOGEN_ENV
    "GEOPROIMPORT_AUTOGEN_INCLUDE=GeoProImportDao"
    "GEOSCHEMEIMPEXP_AUTOGEN_INCLUDE=GeoSchemeImpExp"
    CACHE STRING "Additional QDoc AUTOGEN environment"
)
Здесь указываются только имена CMake-target. Каталоги AUTOGEN_BUILD_DIR/include вычисляются автоматически. Эта настройка нужна, если соответствующие переменные используются непосредственно в .qdocconf. Если QDoc достаточно аргументов -I, автоматический сбор путей уже выполняется без неё.
Команды сборки
Команда	Результат
mingw32-make docs_GeoProjectData	Генерация документации одного модуля
mingw32-make docs_GeoProjectData_rebuild	Принудительная пересборка документации модуля
mingw32-make docs_GeoScheme_index	Генерация документации всех модулей и общего индекса
mingw32-make docs_rebuild_all	Полная пересборка всей документации
Для других генераторов используются соответствующие команды cmake --build.
Что важно проверить перед внедрением
Я восстановил предыдущую версию файла и исходный вариант из твоих файлов, но реальную сборку GeoScheme с установленным Qt и QDoc в этой среде выполнить не могу. Поэтому не буду утверждать, что новая версия уже проверена на твоём проекте.
Есть три отдельных момента, которые нужно проверить на реальном проекте:
	•	AUTOGEN: действительно ли GeoProImportDao и GeoSchemeImpExp являются CMake-target с такими именами. Если это так, новые настройки должны вычислить их каталоги и обеспечить сборку до запуска QDoc.
	•	QDoc: использует ли твой .qdocconf переменные GEOPROIMPORT_AUTOGEN_INCLUDE и GEOSCHEMEIMPEXP_AUTOGEN_INCLUDE. Если использует, их нужно сопоставить с target через GEOSCHEME_QDOC_AUTOGEN_ENV.
	•	Упаковка приложения: этот файл добавляет только установку HTML-документации. Установка исполняемых файлов, библиотек и CPack должны проверяться в корневом CMakeLists.txt и соответствующих install-правилах. Их я намеренно не менял.
Особенно важно: в этой версии я исправил последовательность зависимостей, но окончательно подтвердить её можно только по реальному графу целей твоего GeoImpExp. Для этого следующим шагом нужно проверить CMakeLists.txt каталога GeoImpExp и места, где создаются GeoProImportDao и GeoSchemeImpExp.
